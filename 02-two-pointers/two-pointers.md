# Two Pointers

## Core Idea
Use two indices to eliminate impossible answers after every comparison.

## Goal
Reduce an O(n²) search into O(n).

## Common Triggers
- Sorted array
- Pair search
- Palindrome
- Opposite ends
- Need to compare two elements
- Remove duplicates
- Partitioning

## Types
1. Opposite Ends
2. Same Direction
3. Fast & Slow

## Golden Question
After this comparison, which pointer can I move safely, and why?

## Biggest Lesson
Every pointer movement should eliminate part of the search space.
